Simpsonova formula

Složena Simpsonova metoda počiva na ideji da se geometrijska površina ispod krive funkcije na intervalu podijeli na paran broj n manjih segmenata jednake širine . Na svakom paru susjednih podintervala, stvarna funkcija se aproksimira kvadratnom funkcijom (parabolom). Da bismo metodu lakše povezali sa MATLAB-om, čvorove integracije indeksiramo od 1 do , tako da je prvi čvor , a posljednji .
Ukupna aproksimacija integrala dobija se kao direktna suma površina ispod svih tih pojedinačnih parabola duž cijelog intervala, gdje se preko svaka tri susjedna čvora postavlja jedna parabola:

Ova je metoda četvrtog reda tačnosti, što teorijski znači da će se polovljenjem koraka integracije greška smanjiti približno šesnaest puta.
Kako tačna vrijednost integrala najčešće nije unaprijed poznata, stvarna greška se procjenjuje Rungeovim postupkom. Ovaj postupak zahtijeva da se integral izračuna dva puta: prvo sa početnim brojem podintervala n (što daje rezultat ), a zatim sa dvostruko većim brojem podintervala (što daje tačniji rezultat ). Kada ova procijenjena vrijednost greške padne ispod zadate tolerancije, postupak se prekida, a vrijednost $I_2$ se usvaja kao konačni i dovoljno tačni rezultat integracije.
U nastavku su implementirane dvije funkcije kako bi program bio modularniji i čitljiviji. Prva funkcija, runge_simpson_n, zadužena je za računanje približne vrijednosti integrala i procjenu greške za tačno određeni broj podintervala n. Ona prvo računa integral preko obične složene Simpsonove formule sa trenutnim brojem podintervala, a odmah zatim ponavlja taj postupak sa duplo više podintervala (2n). Na kraju, funkcija koristi razliku ova dva dobijena rezultata i preko Rungeove formule (dijeljenjem sa 15) procjenjuje kolika je greška napravljena pri računanju sa tim brojem tačaka.
function [I1, I2, E] = runge_simpson_n(f, a, b, n)
% RUNGE_SIMPSON_N Računa integral Simpsonovom formulom za n i 2n koraka
% te procjenjuje grešku pomoću Rungeove formule.
 
if mod(n, 2) ~= 0
error("Broj intervala mora biti paran!")
end
 
% Prvi proračun sa 'n' podintervala
h = (b - a) / n;
x = linspace(a, b, n + 1);
I1 = (h / 3) * (f(a) + f(b) + 4 * sum(f(x(2:2:end-1))) + 2 * sum(f(x(3:2:end-2))));
 
% Drugi proračun sa '2n' podintervala
n2 = n * 2;
h2 = (b - a) / n2;
x2 = linspace(a, b, n2 + 1);
I2 = (h2 / 3) * (f(a) + f(b) + 4 * sum(f(x2(2:2:end-1))) + 2 * sum(f(x2(3:2:end-2))));
 
% Procjena greške (za Simpsonovu metodu dijeli se sa 15 jer je red p=4)
E = abs(I1 - I2) / 15;
end
Pošto u praksi obično želimo da izračunamo vrijednost integrala sa zadatom tačnošću, ne možemo unaprijed znati potreban broj podintervala kojim se ta tačnost postiže. Zbog toga se polazi od minimalnog broja podintervala (kod Simpsonove metode početni broj mora biti paran, pa krećemo od n=2), koji se ieterativno duplira sve dok procijenjena greška ne padne ispod zadate tolerancije. Opisani postupak izvršava funkcija runge_simpson_tol.
function [I2, n, E] = runge_simpson_tol(f, a, b, tol)
% Počinjemo od n = 2 podintervala (minimum za Simpsonovu metodu)
n = 2;
while true
% Računamo integral za trenutni n (I1) i za 2n (I2)
[I1, I2, E] = runge_simpson_n(f, a, b, n);
% Ako tačnost nije zadovoljena, broj podintervala se duplira.
% Dupliranje je potrebno izvršiti i u slučaju da smo postigli
% tačnost jer I2 proglašavamo za vrijednost integrala, a za nju
% smo koristili 2n intervala.
n = n * 2;
% Ako je greška dovoljno mala, prekidamo petlju i vraćamo tačan n
if E < tol
break;
end
end
end

Zadaci

1. Simpsonovom formulom izračunati integral: sa tačnošću .
% 1. Definisanje podintegralne funkcije, granica i tolerancije
f = @(x) 1 ./ (x + exp(-x));
a = 0;
b = 1;
tol = 0.005;
 
% 2. Poziv glavne funkcije za adaptivnu integraciju
[vrijednost_integrala, broj_podintervala, procjena_greske] = runge_simpson_tol(f, a, b, tol)
vrijednost_integrala = 0.8916
broj_podintervala = 4
procjena_greske = 3.8617e-05
2. Simpsonovom formulom izračunati integral sa tačnošću .
% 1. Definisanje nove podintegralne funkcije, granica i tolerancije
f = @(x) exp(-x.^2);
a = 0;
b = 1;
tol = 10^(-4);
 
% 2. Poziv glavne funkcije za adaptivnu integraciju
[vrijednost_integrala, broj_podintervala, procjena_greske] = runge_simpson_tol(f, a, b, tol)
vrijednost_integrala = 0.7469
broj_podintervala = 4
procjena_greske = 2.1670e-05
