Trapezna formula

Složena trapezna metoda počiva na ideji da se geometrijska površina ispod krive funkcije na intervalu podijeli na n manjih segmenata jednake širine . Na svakom pojedinačnom podintervalu , stvarna funkcija se aproksimira linearnom funkcijom (tetivom), čime se dobija geometrijski lik trapeza. Ova je metoda drugog reda tačnosti, što teorijski znači da će se polovljenjem koraka integracije greška smanjiti približno četiri puta.
Kako tačna vrijednost integrala u praksi najčešće nije unaprijed poznata, stvarna greška se procjenjuje Rungeovim postupkom. Ovaj postupak zahtijeva da se integral izračuna dva puta: prvo sa početnim brojem podintervala n (što daje rezultat ), a zatim sa dvostruko većim brojem podintervala (što daje tačniji rezultat ). Kada ova procijenjena vrijednost greške padne ispod zadate tolerancije, postupak se prekida, a vrijednost se usvaja kao konačni i dovoljno tačni rezultat integracije.
U nastavku su implementirane dvije funkcije kako bi program bio modularniji i čitljiviji. Prva funkcija, runge_trapez_n, zadužena je za računanje približne vrijednosti integrala i procjenu greške za tačno određeni broj podintervala n. Ona prvo računa integral preko obične složene trapezne formule sa trenutnim brojem podintervala, a odmah zatim ponavlja taj postupak sa duplo više tačaka (2n). Na kraju, funkcija koristi razliku ova dva dobijena rezultata i preko Rungeove formule procjenjuje kolika je greška napravljena pri računanju sa tim brojem tačaka.
function [I1, I2, E] = runge_trapez_n(f, a, b, n)
% RUNGE_TRAPEZ_N Računa integral trapeznom formulom za n i 2n koraka
% te procjenjuje grešku pomoću Rungeove formule.
 
% Prvi proračun sa 'n' podintervala
h = (b - a) / n;
x = linspace(a, b, n + 1);
I1 = (h / 2) * (f(a) + f(b) + 2 * sum(f(x(2:end-1))));
 
% Drugi proračun sa '2n' podintervala
n2 = n * 2;
h2 = (b - a) / n2;
x2 = linspace(a, b, n2 + 1);
I2 = (h2 / 2) * (f(a) + f(b) + 2 * sum(f(x2(2:end-1))));
 
% Procjena greške (za trapeznu metodu dijeli se sa 3)
E = abs(I1 - I2) / 3;
end
Pošto u praksi obično želimo da izračunamo vrijednost integrala sa zadatom tačnošću, ne možemo unaprijed znati potreban broj podintervala kojim se ta tačnost postiže. Zbog toga se polazi od minimalnog broja podintervala, koji se iterativno duplira sve dok procijenjena greška ne padne ispod zadate tolerancije. Opisani postupak izvršava funkcija runge_trapez_tol.
function [I2, n, E] = runge_trapez_tol(f, a, b, tol)
% Počinjemo od n = 1 podintervala
n = 1;
while true
% Računamo integral za trenutni n (I1) i za 2n (I2)
[I1, I2, E] = runge_trapez_n(f, a, b, n);
% Ako tačnost nije zadovoljena, broj podintervala se duplira.
% Dupliranje je potrebno izvršiti i u slučaju da smo postigli
% tačnost je I2 proglašavamo za vrijednost integrala, a za nju
% smo koristili 2n intervala.
n = n * 2;
% Ako je greška dovoljno mala, prekidamo petlju i vraćamo tačan n
if E < tol
break;
end
end
end

Zadaci

1. Trapeznom formulom izračunati integral: sa tačnošću .
% 1. Definisanje podintegralne funkcije, granica i tolerancije
f = @(x) 1 ./ (x + exp(-x));
a = 0;
b = 1;
tol = 0.005;
 
% 2. Poziv glavne funkcije za adaptivnu integraciju
[vrijednost_integrala, broj_podintervala, procjena_greske] = runge_trapez_tol(f, a, b, tol)
vrijednost_integrala = 0.8898
broj_podintervala = 4
procjena_greske = 0.0017
Za prvojeru dobijene vrijednosti možemo koristiti ugrađenu funkciju integral. Rungeova ocjena greške može odstupati od stvarne greške.
integral(f, a, b)
ans = 0.8916
2. Trapeznom formulom izračunati integral sa tačnošću .
% 1. Definisanje nove podintegralne funkcije, granica i tolerancije
f = @(x) exp(-x.^2);
a = 0;
b = 1;
tol = 10^(-4);
 
% 2. Poziv glavne funkcije za adaptivnu integraciju
[vrijednost_integrala, broj_podintervala, procjena_greske] = runge_trapez_tol(f, a, b, tol)
vrijednost_integrala = 0.7468
broj_podintervala = 32
procjena_greske = 5.9886e-05
