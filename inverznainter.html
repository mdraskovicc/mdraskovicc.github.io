Inverzna interpolacija

Inverzna interpolacija zasniva se na zamjeni uloga nezavisne i zavisne promjenljive. Umjesto da se interpolira funkcija u obliku , konstruiše se interpolacioni polinom kojim se aproksimira x kao funkcija od y.
Na taj način, za zadatu vrijednost p može se odrediti približna vrijednost t takva da važi . Zbog toga se inverzna interpolacija može koristiti kao metoda za približno rješavanje nelinearnih jednačina.
U ovom primjeru biće implementiran Lagranžev interpolacioni polinom, ali se može koristiti bilo koji oblik interpolacionog polinoma.
function t = inverzna(x, y, p)
n = length(x);
t = 0;
 
for i = 1:n
l = 1;
 
for j = 1:n
if j ~= i
l = l * (p - y(j)) / (y(i) - y(j));
end
end
 
t = t + x(i) * l;
end
end

Zadaci

1. Lagranževim interpolacionim polinomom aproksimirati funkciju zadatu sljedećom tablicom:
izračunati približnu vrijednost x tako da važi .
x = [0 1 2 3 4];
y = [-5 1 9 25 55];
p = 37.875;
 
inverzna(x, y, p)
ans = 3.2425
2. Primjenom inverzne interpolacije odrediti približnu vrijednost broja x za koji važi koristeći Lagranžev interpolacioni polinom konstruisan u čvorovima .
f = @(x) log(x.^2 + 1);
x = [2 3 4 5 6];
p = 2.5;
 
t = inverzna(x, f(x), p)
t = 3.3441
% tacna vrijednost f^(-1) (2.5)
f_inv = @(y) sqrt(exp(y) - 1);
f_inv(p)
ans = 3.3440
