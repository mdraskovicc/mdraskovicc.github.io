Metoda Runge-Kuta

Metoda Runge–Kuta četvrtog reda direktno je inspirisana i zasnovana na sličnoj ideji kao obična Ojlerova metoda, ali sa ciljem postizanja znatno veće tačnosti. Dok obična Ojlerova metoda aproksimira integral (priraštaj) na podintervalu koristeći u samo jednoj tački (lijevom kraju), ova metoda na svakom pojedinačnom podintervalu koristi četiri različite aproksimacije integrala, označene sa i .
Ove aproksimacije dobijaju se tako što se desna strana diferencijalne jednačine sukcesivno računa u pažljivo odabranim čvorovima x unutar posmatranog podintervala, dok se nepoznate vrijednosti rješenja u tim čvorovima zamjenjuju njihovim trenutnim aproksimacijama.
Proces uzorkovanja unutar jednog podintervala širine h odvija se kroz sljedeća četiri koraka:
1. je početni, grubi priraštaj izračunat na osnovu vrijednosti izvodne funkcije na samom lijevom kraju podintervala ()
2. je priraštaj izračunat na osnovu prve unutrašnje (na sredini podintervala, ), gdje se nepoznata vrijednost rješenja aproksimira skaliranjem prethodnog priraštaja na polovinu ()
3. je popravljeni priraštaj izračunat na osnovu iste unutrašnje tačke, ali sa boljom aproksimacijom vrijednosti rješenja pomoću prethodno izračunate brzine promjene kroz (odnosno )
4. je priraštaj izračunat na osnovu desnog kraja podintervala (), gdje se vrijednost rješenja aproksimira pomoću punog priraštaja iz prethodnog koraka ()
Konačno rješenje u sljedećem čvoru računa se kao težinska sredina ova četiri priraštaja, u kojoj najveći uticaj (dvostruko veću težinu) imaju procjene iz unutrašnjih tačaka sa sredine podintervala:
function [x, y] = runge_kuta_4(f, a, p, b, n)
% Parametri:
% f : funkcija koja predstavlja desnu stranu jednačine y' = f(x, y)
% a : početak intervala
% p : početni uslov y(a) = p
% b : kraj intervala
% n : ukupan broj tačaka (indeksirane od 1 do n)
 
% Računanje koraka integracije na osnovu n tačaka na intervalu [a, b]
h = (b - a) / (n - 1);
% Inicijalizacija vektora dužine n
x = linspace(a, b, n);
y = zeros(1, n);
y(1) = p;
% Iterativno računanje vrijednosti
% Petlja ide od 1 do n-1, prateći matematičke indekse
for i = 1:(n - 1)
k1 = h * f(x(i), y(i));
k2 = h * f(x(i) + h/2, y(i) + k1/2);
k3 = h * f(x(i) + h/2, y(i) + k2/2);
k4 = h * f(x(i) + h, y(i) + k3);
% Računanje konačne vrijednosti (h je već uračunato kroz koeficijente)
y(i+1) = y(i) + (1 / 6) * (k1 + 2*k2 + 2*k3 + k4);
end
end

a = 0.0;
p = 0.0;
b = 1.0;
n = 6;
