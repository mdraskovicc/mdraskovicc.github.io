Metoda polovljenja intervala

Metoda polovljenja intervala je numerička metoda za nalaženje približne nule funkcije , tj. rješenja jednačine . Zasniva se na činjenici da ako je funkcija neprekidna na intervalu i ako važi , tada funkcija mora imati bar jednu nulu u tom intervalu.
Postupak ide tako što se interval stalno polovi. Računa se sredina . Zatim se provjerava znak funkcije u tački c. Ako je , nova aproksimacija nule nalazi se u intervalu , a u suprotnom u intervalu . Proces se ponavlja dok interval ne postane dovoljno mali ili dok vrijednost funkcije u sredini ne bude dovoljno blizu nuli.
Metoda je spora, ali vrlo pouzdana jer uvijek konvergira ako su ispunjeni uslovi neprekidnosti i promjene znaka.
Funkciju polovljenje(f, a, b, tol) možemo implementirati u posebnom fajlu polovljenje.m, tako da kao argumente prima funkciju čija se nula traži, krajeve intervala u kom se nula nalazi i traženu tačnost. Povratne vrijednosti su nula funkcije f i broj iteracija. Nakon implementacije, funkciju je moguće pozivati u komandnom prozoru ili nekom .m fajlu.
function [x, iter] = polovljenje(f, a, b, tol)
 
if f(a) * f(b) > 0
error('Uslovi nisu ispunjeni')
end
 
iter = 0;
while abs(b - a) > tol
c = (a + b) / 2;
iter = iter + 1;
 
if f(a) * f(c) < 0
b = c;
else
a = c;
end
end
x = (a + b) / 2;
end

Zadaci

1. Riješiti jednačinu sa tačnošću .
f = @(x) exp(-x) - x;
f(0)
ans = 1
f(1)
ans = -0.6321
a = 0;
b = 1;
tol = 1e-4;
[x, iter] = polovljenje(f, a, b, tol)
x = 0.5672
iter = 14
% provjera
disp("f(x*) = " + num2str(f(x))) % num2str konvertuje broj u string
f(x*) = -4.0587e-05
