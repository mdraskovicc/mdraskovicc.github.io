Gaus-Zajdelova metoda

Gaus–Zajdelova metoda dobija se iz Jakobijeve metode. Posmatramo sistem , gdje se matrica A razdvaja na dijagonalni dio i ostatak . Kao i kod Jakobijeve metode, sistem je ekvivalentan i može se zapisati kao problem fiksne tačke .
Razlika je u tome što se kod Gaus–Zajdelove metode nove vrijednosti komponenata koriste odmah čim se izračunaju, za razliku od Jakobijeve metode gdje se sve komponente računaju koristeći samo vrijednosti iz prethodne iteracije. Iterativni niz računa se po formuli
Kao i kod Jakobijeve metode, konvergencija je zagarantovana ako je matrica A strogo dijagonalno dominantna.
Implementacija ove metode je skoro ista kao implementacija Jakobijeve metode, samo što se svaka koordinata novog vektora u iterativnom nizu računa posebno i kroiste se prethodno izračunate koordinate novog vektora.
function [x, iter] = gauszajdel(A, b, x0, tol, max_iter)
R = A - diag(diag(A));
d = diag(A); % vektor dijagonala matrice A
iter = 0;
 
while iter < max_iter
% kopiramo prethodnu tacku iterativnog niza u novu tacku
% iterativnog niza i azuriramo koordinatu po koordinatu
iter = iter + 1;
x1 = x0;
for i = 1:length(x1)
% Vektor x1 na pozicijama manjim od i
% sadrzi nove vrijednosti, a na ostalim pozicijama
% vrijednosti iz prethodne iteracije
x1(i, 1) = (b(i) - R(i, :) * x1) / d(i);
end
 
if norm(x1 - x0, inf) < tol
break;
end
x0 = x1;
end
 
x = x1;
if iter == max_iter
disp('Dostignut maksimalan broj iteracija');
end
end
