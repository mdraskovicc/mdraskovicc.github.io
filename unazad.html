U svakoj iteraciji dodaje se novi član interpolacionog polinoma: Iterativnim računanjem proizvoda i faktorijela izbjegava se njihovo ponovno računanje za svaki član posebno, čime se smanjuje broj računskih operacija i povećava efikasnost algoritma. Konačna vrijednost interpolacionog polinoma vraća se kroz promjenljivu p.
function p = unazad(x, y, t)
 
h = x(2) - x(1);
u = (t - x(end)) / h;
 
n = length(x);
 
D = zeros(n, n);
D(:,1) = y(:);
 
% Tabela konačnih razlika
for j = 2:n
D(1:n-j+1, j) = D(2:n-j+2, j-1) - D(1:n-j+1, j-1);
end
 
p = 0;
 
b = 1;
f = 1;
 
% Njutnov polinom unazad
for k = 1:n
p = p + (b / f) * D(n-k+1, k);
 
b = b * (u + k - 1);
f = f * k;
end
end
