Njutnova metoda

Njutnova metoda je iterativni postupak koji za traženje nule funkcije koristi linearnu aproksimaciju funkcije njenom tangentom u nekoj tački. Polazi se od početne aproksimacije , a zatim se u svakoj iteraciji konstruiše tangenta na grafik funkcije u tački . Presjek te tangente sa x-osom daje novu aproksimaciju .
Iterativni niz dobija se po formuli
Geometrijski posmatrano, u svakoj iteraciji funkcija se lokalno zamjenjuje pravom koja najbolje aproksimira njen tok u datoj tački. Zbog toga metoda često postiže vrlo brzu konvergenciju kada je početna aproksimacija dovoljno blizu rješenja i kada je izvod funkcije različit od nule u njegovoj okolini.
Teorema. Neka je i neka je . Ako su ispunjeni uslovi:
  1. i ne mijenjaju znak na ,
  2. početna aproksimacija zadovoljava uslov
tada niz definisan Njutnovom metodom konvergira ka jedinstvenom rješenju .
Navedeni uslovi nisu neophodni za konvergenciju, tj. ne moraju biti ispunjeni da bi metoda konvergirala, ali su dovoljni i poželjno je da budu zadovoljeni. Za početnu tačku biraćemo jedan od krajeva intervala.
function [x, iter] = njutn(f, f1, f2, l, d, tol)
 
if f(l) * f(d) > 0
error('Nije ispunjen uslov')
end
 
if f2(l) * f(l) > 0
x0 = l;
elseif f2(d) * f(d) > 0
x0 = d;
else
error("Nije ispunjen uslov")
end
 
iter = 0;
while true
x1 = x0 - f(x0) / f1(x0);
iter = iter + 1;
 
if abs(x1 - x0) < tol
break
end
x0 = x1;
end
x = x1;
end
Funkciju je mogće implementirati i tako da vraća čitav iterativni niz.
function [X, Xend, iter] = njutn2(f, f1, f2, l, d, tol)
 
if f(l) * f(d) > 0
error('Nije ispunjen uslov')
end
 
if f2(l) * f(l) > 0
X = l;
elseif f2(d) * f(d) > 0
X = d;
else
error("Nije ispunjen uslov")
end
 
iter = 0;
while true
X = [X, X(end) - f(X(end)) / f1(X(end))]; % prosirujemo niz novom tackom
iter = iter + 1;
 
if abs(X(end) - X(end - 1)) < tol
break
end
end
 
Xend = X(end);
end

Nacrtaćemo iterativni niz tako da tačke budu obojene svjetlijom crvenom bojom što su bliže nuli funkcije. U MATLAB-u se boje označavaju kao vektor sačinjen od tri komponente, crvene, zelene i plave, čije su vrijednosti u intervalu [0, 1]. Na primjer, [1 1 1] ozačava bijelu boju, [1 0 0] crvenu, a [1 1 0] žutu. Početna tačka iterativnog niza imaće boju [0.4 0 0] - tamna crvena, a krajnja [1 0 0] svijetla crvena.
n = length(X);
xx = linspace(l, d);
yy = f(xx);
