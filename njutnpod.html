Njutnov interpolacioni polinom sa podijeljenim razlikama

Njutnov interpolacioni polinom predstavlja alternativni način zapisivanja interpolacionog polinoma koji prolazi kroz zadati skup tačaka . Za razliku od Lagranžove metode, Njutnov polinom se konstruiše preko podijeljenih razlika, što omogućava lakše dodavanje novih tačaka. Polinom se zapisuje u obliku:
Koeficijenti predstavljaju vrijednosti iz prvog reda tabele podijeljenih razlika.
Funkcija podijeljene_razlike prima vektore poznatih čvorova X i Y. Unutar funkcije se formira pomoćna matrica A dimenzija . Prva kolona ove matrice popunjava se vrijednostima Y, dok se svaka naredna kolona računa rekurzivno preko prethodne kolone i razlika odgovarajućih čvorova iz vektora X. Matrica A se popunjava tako da se ispod sporedne dijagonale nalaze nule:
Funkcija na kraju izdvaja i vraća samo prvi red matrice A (vektor a), koji sadrži tražene koeficijente polinoma: .
function a = podijeljene_razlike(X, Y)
% X i Y su kolone
n = length(X);
A = zeros(n,n);
A(:,1) = Y;
 
for j = 2:n
A(1:n - j + 1, j) = (A(2:n - j + 2, j - 1) - A(1:n - j + 1, j - 1)) ...
./ (X(j:n) - X(1:n - j + 1));
end
a = A(1,:);
end
Nakon što su koeficijenti izračunati, funkcija njutn vrši brzu evaluaciju polinoma stepena najviše u zadatoj tački t. Ona kao ulazne parametre prima izračunate koeficijente a, čvorove X i tačku t. Računanje se vrši Hornerovom šemom, izvlačenjem promjenljivih ispred zagrada, čime se izraz transformiše u formu:
U kodu funkcije njutn, ovaj račun se izvršava unazad (od unutrašnjih zagrada ka spoljašnjim) pomoću petlje for i = n-1 : -1 : 1. Algoritam počinje od posljednjeg koeficijenta i u svakom koraku množi trenutnu vrijednost sa zagradom te joj dodaje prethodni koeficijent. Ovim postupkom se izbjegava ponovno množenje istih zagrada, čime se broj računskih operacija svodi na minimum, a krajnji rezultat se vraća u promjenljivoj p.
function p = njutn(a, X, t)
n = length(a);
p = a(n);
 
for i = n - 1 : -1 : 1
p = a(i) + (t - X(i)) * p;
end
end
Zadaci
1. Izračunati za tablično zadatu funkciju:
koristeći Njutnov interpolacioni polinom sa podjeljenim razlikama.
X = [1 2 3]';
Y = [3 1 2]';
% X i Y su kolone
a = podijeljene_razlike(X, Y);
 
p = njutn(a, X, 2.3)
p = 0.9850
2. Izračunati za tablično zadatu funkciju:
koristeći Njutnov interpolacioni polinom sa podjeljenim razlikama.
X = [-2 1 2 5]';
Y = [34 -2 -10 62]';
% X i Y su kolone
a = podijeljene_razlike(X, Y);
 
p = njutn(a, X, 3)
p = -6
