Ukoliko matrica A nije dijagonalno dominantna, sistem je potrebno transformisati u ekvivalentan tako da nova matrica sistema bude dijagonalno dominantna.
Kao kriterijum zaustavljanja koristi se maksimalan broj iteracija i uslov , gdje je ∞-norma vektora definisana je kao .
function [x, iter] = jakobi(A, b, x0, tol, max_iter)
% diag(A) je dijagonala matrice A,
% diag(diag(A)) je matrica koja ima istu dijagonalu kao A,
% a na svim ostalim mjestima 0
D = diag(diag(A));
R = A - D;
 
% Inverz matrice D se racuna jednostavno
invD = diag(1 ./ diag(A));
iter = 0;
 
while iter < max_iter
x1 = invD * (b - R*x0);
iter = iter + 1;
if norm(x1 - x0, inf) < tol
break;
end
x0 = x1;
end
 
x = x1;
if iter == max_iter
disp('Dostignut maksimalan broj iteracija');
end
end
